Connecting the farm

This gives every person on the farm their own account, so a farm hand's phone is never sent wages or sales. It is free and takes about five minutes.

Two ways to do this The first involves no pasting at all. Try that one.

Easiest: point Deno at the repository

Deno Deploy can run a file straight out of your own GitHub repository, so there is nothing to copy and nothing to keep up to date by hand.

  1. Go to dash.deno.com and sign in with GitHub.
  2. Create a New Project and choose the option to deploy from a GitHub repository rather than a Playground.
  3. Pick the repository Stock- and the branch claude/stock-selector-allocator-app-8lic01.
  4. When it asks for the entry point file, give it: 
    douvalue/server/deno-sync.ts
  5. Deploy. Skip to step 3 below for what happens next.

Done this way, the server updates itself whenever the farm app is improved, because it is running the file in your repository rather than a copy.

Or: paste it into a Playground

Use this if you cannot find the GitHub option, or you would rather the server were a copy that never changes on its own.

1. Open Deno Deploy and start a Playground

Go to dash.deno.com and sign in with GitHub. Look for New Playground. On some versions it sits behind New Project first.

A Playground opens a code editor with a short example already in it, usually something with Deno.serve. That example is what you replace.

Tap into the editor, select everything that is there (Ctrl+A, or Cmd+A on a Mac), and delete it. The editor should be empty before you paste.

2. Paste this one line

That is the whole thing. It loads the farm server from your own site.

import "https://samebimo10-cpu.github.io/Stock-/farm/server/deno-entry.js";
Rather paste the whole thing?

If you would prefer the server to have no link back to this site, copy the full file instead. It is long, so use the button rather than selecting by hand. Both do exactly the same job.

You can also read it at deno-entry.js.

3. Save and deploy

Press Save & Deploy, usually at the top right. It takes a few seconds.

Your address then appears at the top of the page. It looks like https://something-something-12.deno.dev.

Open that address in a new tab. If it says DouValue farm server is running, it worked.

4. Tell the app about it

In the farm app: Settings, then Sync, then Connect the farm. Paste the address, choose your PIN, and press Create the farm.

After that, People → Add someone gives you a link and a password to send each person. They tap the link, type the password once, pick their own PIN, and that phone is theirs.

Use the https address Deno gives you an https address. Use it exactly as shown. PINs travel in the request, and plain http would put them on the wire in clear.

If something looks different

Deno Deploy changes its screens from time to time, so the buttons may not be worded exactly as above. What you are looking for is any way to create a Playground, which is simply an editor that runs one file.

If you get stuck, tell Claude what you can see on the screen and it will work out the rest.

Everything here runs on your own accounts. The farm's records live on your Deno project and on the phones, and nowhere else.
